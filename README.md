# Investment Preferences Dataset

## About the Dataset
This dataset was collected through Google Forms as a personal project during the COVID-19 lockdown. It explores people's investment preferences, behaviors, and financial objectives.

## Dataset Description
The dataset includes information about respondents' demographics and investment habits, covering:

- **Demographics:** Gender and age
- **Investment Preferences:** Preferred investment options, including mutual funds, equity markets, government bonds, fixed deposits, gold, and others.
- **Investment Behavior:** Stock market participation, investment factors, and monitoring frequency.
- **Financial Goals:** Investment objectives, purposes, savings goals, and expected returns.
- **Information Sources:** Sources of investment-related information.
